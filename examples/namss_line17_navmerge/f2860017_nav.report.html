Notes

  • Matched trace-header FFID (field record) (byte 9) to navigation column 'col5' on line 'F286-17': 100.0% of the file's key values appear in the navigation.
  • The navigation is latitude/longitude with no stated datum; WGS 84 was assumed. For 1980s data the datum may be NAD27/WGS 72 (differences of tens to ~200 m). Pass --nav-epsg to set it.
  • 150 traces had no exact navigation record and were linearly interpolated between neighbouring points.
