Add positions from a navigation file

Older seismic lines often keep their positions in a separate navigation file. Segwise matches it to the traces by shot or CDP number and writes a file with coordinates.

1

Check the line

On Check files, check the SEG-Y line.

2

Open “Write a fixed copy”

Choose “Add positions from a navigation file”.

3

Point to the nav file

UKOOA P1/90, CSV or a text table all work.
